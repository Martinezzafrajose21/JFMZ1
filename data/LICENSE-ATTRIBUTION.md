# Auto MPG: procedencia y atribución

El archivo `auto-mpg.data` procede de UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/9/auto

Cita: Quinlan, R. (1993). *Auto MPG* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5859H

La página del conjunto indica licencia Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/

Se distribuye el archivo original sin alterar sus 398 registros. La aplicación puede generar `auto_mpg.csv` como copia procesada local, que queda excluida del repositorio.
